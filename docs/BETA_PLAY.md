# Three Game — Beta build

**Version:** v0.1.0-beta.2  
**Platforms:** macOS (Apple Silicon + Intel) · Windows 64-bit

**Download:** https://github.com/DinisMiranda/three_game/releases/latest

## Install

### macOS

1. Download `ThreeGame_macOS.zip`.
2. Double-click to unzip.
3. Open `Three Game.app`.

#### macOS security warning

This build is not notarized. On first launch:

1. Right-click **Three Game.app**
2. Choose **Open**
3. Confirm **Open** in the dialog

Or: **System Settings → Privacy & Security → Open Anyway**

### Windows

1. Download `ThreeGame_Windows.zip`.
2. Right-click the zip → **Extract All…**
3. Run `Three Game.exe`.

If SmartScreen blocks the app: click **More info** → **Run anyway** (unsigned beta build).

## What to play

1. **Start** → briefing → tactical map
2. Select **Meridian Spire** → **Deploy**
3. Clear **3 floors** (rooftop boss: Custodian Unit)
4. Continue through the **story** (epilogue → pick hideout → meet full squad)
